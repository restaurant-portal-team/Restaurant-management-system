GLOBAL API CONVENTIONS (F01)
- Error body for all non-health errors: {"statusCode","error","message","requestId","timestamp"}; 5xx always returns
  a generic message; no stack traces, SQL, paths or config values are ever returned.
- CORS: explicit allowlist from CORS_ORIGIN (default http://localhost:5173); "*" rejected; credentials enabled for
  future cookie auth (F03); disallowed origins receive no CORS headers.
- Validation: global ValidationPipe (whitelist, forbidNonWhitelisted, forbidUnknownValues, transform).
- Every response carries X-Request-Id (caller value accepted only if /^[A-Za-z0-9-]{8,64}$/).
