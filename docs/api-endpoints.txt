FEATURE ID: F03
METHOD + PATH: POST /api/v1/auth/login
STATUS: IMPLEMENTED (code + unit/e2e tests 2026-11-20; live API + human browser verification 2026-11-20)
AUTH / ROLES: Public (@Public). Origin header must be in CORS_ORIGIN (403 otherwise). Rate limit 5/min per client IP (429).
REQUEST DTO / VALIDATION: LoginDto {email: string, trimmed, valid email, max 254; password: string, 1-256}. Unknown
        fields -> 400. Email is lower-cased server-side.
SUCCESS RESPONSE: 200 {"user":{"id","fullName","email","role"}} + Set-Cookie rmp_session=<opaque 43-char token>;
        HttpOnly; SameSite=Strict; Path=/api/v1; Expires=+12h (Secure in production). Cache-Control: no-store.
        A new session is created on every login; a session cookie sent with the request is revoked.
ERROR RESPONSES: 400 validation; 401 "Invalid email or password." for unknown, wrong-password, inactive and
        not-yet-activated accounts alike (equalised Argon2 timing); 403 origin; 429 rate limit.
BACKEND CONTROLLER / SERVICE: backend/src/auth/auth.controller.ts, auth.service.ts, session.service.ts, password.ts.
FRONTEND CONSUMER: frontend/src/features/auth/use-auth.ts (useLogin) -> routes/login-page.tsx.
TEST EVIDENCE: backend unit (auth.service.spec.ts, password.spec.ts, session.service.spec.ts); backend e2e
        (auth.e2e-spec.ts: cookie flags, generic 401s, 400 validation, 403 origin, 429, no secrets in body,
        re-login revokes old session); frontend (login-page.test.tsx).

GLOBAL API CONVENTIONS (F01)
- Error body for all non-health errors: {"statusCode","error","message","requestId","timestamp"}; 5xx always returns
  a generic message; no stack traces, SQL, paths or config values are ever returned.
- CORS: explicit allowlist from CORS_ORIGIN (default http://localhost:5173); "*" rejected; credentials enabled for
  future cookie auth (F03); disallowed origins receive no CORS headers.
- Validation: global ValidationPipe (whitelist, forbidNonWhitelisted, forbidUnknownValues, transform).
- Every response carries X-Request-Id (caller value accepted only if /^[A-Za-z0-9-]{8,64}$/).
- Authentication (F03): global deny-by-default SessionAuthGuard; @Public() routes: GET /health, POST /auth/login,
  POST /auth/logout, POST /staff/setup-password (F05). RolesGuard enforces @Roles(...) with the role read from the database. 401 message
  "Authentication required."; 403 "You do not have permission to perform this action.".
- CSRF (F03): POST/PUT/PATCH/DELETE require an Origin header from CORS_ORIGIN (403 "Request origin is not allowed.").
